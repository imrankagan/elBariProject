# ElBari Uygunluk Test Vektorleri
# Bicim surumu: 3
#
# Bu dosya bicimin DONMUS referansidir. Bagimsiz bir implementasyon
# ayni girdilerden ayni ciktilari uretebiliyorsa bicime uygundur.
#
# Alanlar:
#   VEKTOR <ad>        test adi
#   ACIKLAMA <metin>   neyi sinadigi
#   KATMAN <ad>        cekirdek | kanal | cerceve | float_xor | float_kuantala
#   KANAL <n>          kanal sayisi
#   SIRANO <n>         cerceve sira numarasi
#   GIRDI <sayilar>    bosluk ayrilmis int32 degerler
#   GIRDIF <hex>       float32 degerler, BIT DESENI olarak (8 hex basamak)
#                      Metin gosterimi belirsizlik yaratacagi icin bit
#                      deseni kullanilir; NaN/-0 gibi degerler de tasinir.
#   OLCEKLER <hex>     kanal basina kuantalama olcegi (float bit deseni)
#   CIKTI <hex>        beklenen bayt dizisi (kucuk harf hex)
#   SON

VEKTOR cekirdek_sifir_kosusu
ACIKLAMA Blok-ustu sifir kosusu (bicim surumu 3). 200 ozdes deger, yani
ACIKLAMA 24 tam sifir blok. Surum 2'de her blok kendi 4 bitlik etiketini
ACIKLAMA yazardi; surum 3'te hepsi TEK kacisla yazilir - 8 bayt.
ACIKLAMA Kacis kodu: etiket "mod 0 + aykiri_var 1" + maske 0x00 + 16 bit
ACIKLAMA kosu uzunlugu. Bu birlesim surum 2'de ULASILAMAZDIR, cunku
ACIKLAMA aykiri_var ancak maske sifir degilken kurulur - bu sayede surum 2
ACIKLAMA akislari surum 3 cozucusunde aynen calisir.
