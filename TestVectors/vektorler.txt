# ElBari Uygunluk Test Vektorleri
# Bicim surumu: 1
#
# Bu dosya bicimin DONMUS referansidir. Bagimsiz bir implementasyon
# ayni girdilerden ayni ciktilari uretebiliyorsa bicime uygundur.
#
# Alanlar:
#   VEKTOR <ad>        test adi
#   ACIKLAMA <metin>   neyi sinadigi
#   KATMAN <ad>        cekirdek | kanal | cerceve
#   KANAL <n>          kanal sayisi (kanal/cerceve icin)
#   SIRANO <n>         cerceve sira numarasi (cerceve icin)
#   GIRDI <sayilar>    bosluk ayrilmis int32 degerler
#   CIKTI <hex>        beklenen bayt dizisi (kucuk harf hex)
#   SON

VEKTOR cekirdek_2bit
ACIKLAMA 2 bit genislik: farklar yalnizca 0 ve +1
KATMAN cekirdek
GIRDI 1000 1001 1001 1002 1002 1003 1003 1004 1004
CIKTI e8030000101101
SON

VEKTOR cekirdek_4bit

KATMAN cekirdek
